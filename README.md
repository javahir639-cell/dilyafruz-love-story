# DILAFRUZ — OUR LOVE STORY

Интерактивная романтическая история на HTML, CSS и JavaScript-модулях без фреймворков.

## Запуск

Откройте папку через локальный веб-сервер (например, расширение Live Server в VS Code), затем перейдите на `index.html`. Это нужно для корректной загрузки ES-модулей.

## Персонализация

Ключевые параметры находятся в `js/config.js`: имя, дата отношений, музыка, пароль и режим редактирования. Дата намеренно не задана — на сайте выводится «Наша история продолжается».

## Статус этапа 2

Готовы 20 интерактивных глав, три мини-игры, последовательное разблокирование, кинематографические сцены, коллекция 100 причин, викторина, купоны, Canvas-сердце и финал. Персональный текст, подписи, причины, вопросы и купоны редактируются в соответствующих файлах папки `data/`.

## Материалы автора

Создатель добавляет все фотографии, тексты и аудио заранее. Посетитель сайта не загружает, не удаляет и не редактирует материалы.

### Фотографии

Реестр находится в `data/photos.js`:

- `assets/photos/chapter-01.jpg` … `chapter-20.jpg` — отдельные фото глав;
- `assets/photos/letter-01.jpg` … `letter-20.jpg` — фотографии конвертов;
- `assets/photos/secret-room.jpg` — главная фотография секретной комнаты;
- `assets/photos/photo01.jpg` … `photo10.jpg` — две личные галереи по пять фотографий: 01–05 для главы «Наши фотографии», 06–10 для главы «Наши моменты».

После добавления файла установите `enabled: true` и добавьте подпись. Если фотографии для конверта нет, включённая фотография соответствующей главы используется автоматически. Для финала добавьте до трёх фотографий `finale-01.jpg`, `finale-02.jpg`, `finale-03.jpg`. Сайт не запрашивает отключённые изображения, поэтому не создаёт 404 до наполнения материалов.

### Конверты-награды

В `data/envelopes.js` находятся 20 отдельных редактируемых писем. Заполните `title` и `message` перед публикацией. После выполнения главы посетитель сначала открывает конверт, затем нажимает «Продолжить» — только тогда разблокируется следующая глава.

Музыка и голос подключаются после добавления файлов в `assets/music/` и `assets/voice/`; затем внесите имена подключённых треков в `availableTracks` файла `js/config.js`. Такой способ исключает сетевые запросы к отсутствующим локальным файлам.
